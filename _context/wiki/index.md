This wiki gives AI assistants the context they need to better understand our team, product, processes, and tools.

**Navigation tip**: Start with each section's `index.md` before going deeper. Load only what you need — don't read the wiki in full.

## Team

Open-source project maintained on GitHub. Includes AI contributor policy (issue assignment, PR authorship, attribution).

**Learn more**: [Team overview](team/index.md)

## Product

Kaoto is a visual, low-code editor for Apache Camel integrations. It lets users create, edit, and manage Camel routes using a graphical canvas — without needing to hand-write YAML or Java DSL.

**Learn more**: [Product overview](product/index.md) · [Task-to-code map](product/task-map.md) · [Architectural constraints](product/architecture.md)
