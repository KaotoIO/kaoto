# Team overview

## Team mission

Make Apache Camel accessible to integration developers through a modern, visual UI. The Kaoto team builds and maintains the graphical editor that lets users create, edit, and manage Camel integrations without hand-writing DSL code.

## How to reach the maintainers

- **GitHub Issues**: [github.com/KaotoIO/kaoto/issues](https://github.com/KaotoIO/kaoto/issues) — the primary channel for bug reports, feature requests, and contribution discussions
- **GitHub Discussions**: available on the repository for broader questions

## AI contributor policy

The Kaoto team welcomes contributions assisted by AI agents. The policy below clarifies exactly what agents can and cannot do independently.

| Permission | Agent | Human operator |
|------------|-------|----------------|
| Open a GitHub Issue | ✅ Allowed | ✅ Allowed |
| Be *assigned* to an issue | ❌ Not supported — assign the human operator | ✅ Assign the human |
| Create a branch on a fork | ✅ Allowed | ✅ Allowed |
| Push commits to a branch the agent created | ✅ Allowed | ✅ Allowed |
| Open a pull request | ❌ Not independently — human must open or approve before submission | ✅ Opens or approves |
| Appear in commit authorship | Use the human operator's Git identity; AI tool may be noted in the PR description | ✅ Human is the committer |
| Receive credit in changelog / release notes | Mention in PR description is encouraged; changelog entries use the human's GitHub handle | N/A |
| Respond to maintainer review comments | ❌ Human must respond | ✅ Required |

**Equal quality standard**: AI-assisted contributions are held to the same code quality, test coverage, and review standards as human-only contributions. There are no lower or higher bars.

**Accountability**: The human operator is accountable for all AI-generated code — for correctness, for responding to maintainer feedback, and for following up on PR comments. PRs without a response after **one week** will be closed (maintainers may extend this on request).

**Disclosure**: Mentioning the AI tool used in the PR description is encouraged. It helps the team improve [AGENTS.md](../../../AGENTS.md).
